# 📚 מערכת לניהול וחיפוש כרטיסיות תלמידים וצוות (אופליין)

אפליקציית ווב מתקדמת (PWA) מבוססת צד-לקוח בלבד (HTML / CSS / JavaScript), המיועדת לניהול, חיפוש וצפייה בנתוני תלמידים ואנשי צוות על גבי מכשירים ניידים (אנדרואיד) ומחשבים – **ללא צורך בחיבור לאינטרנט** וללא תלות בשרת חיצוני.

---

## 🎯 תכונות עיקריות במערכת

* **עבודה מלאה באופליין (Offline-First):** שימוש ב-`Service Worker` וב-`localStorage` לשמירת קובץ המערכת והנתונים בזיכרון המקומי של המכשיר.
* **יבוא קובצי CSV חכם:** מנוע פיענוח עצמאי המזהה אוטומטית מפרידים (פסיק, נקודה-פסיק, טאב), מנקה תווי BOM נסתרים ומטפל במרכאות כפולות.
* **טיפול בפורמטים של אקסל:** פענוח אוטומטי של מספרי זיהוי שהוצגו בפורמט מדעי (`E+`) ושמירה על שלמות הספרות.
* **חישוב גיל דינמי ומדויק:** המרת תאריכי לידה בכל הפורמטים הנפוצים להצגת גיל מדויק ברמת חודשים (למשל `13.3`).
* **סיווג ומיון חכם:** הפרדה ויזואלית ברורה בין אנשי צוות, תלמידים פעילים, תלמידים בכיתות גבוהות, ותלמידים שסיימו/עזבו (כולל זיהוי אוטומטי של כיתות ישיבה קטנה וגדולה).
* **איתור אחים ומשפחות:** כפתור ייעודי לשליפה מיידית של כל בני המשפחה על בסיס תעודת זהות הורה או מספר טלפון משותף.
* **חיוג מהיר בלחיצה:** הפיכת כל מספרי הטלפון בכרטיסייה לכפתורי חיוג ישירים (`tel:`).

## 🗂️ מבנה קובץ ה-CSV הנדרש

המערכת קוראת קובץ CSV מקודד ב-UTF-8 הכולל את שורת הכותרות הבאה:

| שם העמודה | תיאור ותפקיד במערכת |
| :--- | :--- |
| **`מס'`** | מספר סידורי בקובץ המקורי. |
| **`שם משפחה`** | שם המשפחה של התלמיד או איש הצוות. |
| **`שם פרטי`** | השם הפרטי של התלמיד או איש הצוות. |
| **`מס. ת.ז.`** | מספר תעודת הזהות (תומך גם בפורמט מדעי מאקסל). |
| **`תאריך לידה`** | תאריך לידה לועזי (משמש לחישוב הגיל המדויק). |
| **`תאריך לידה עברי`** | תאריך לידה עברי לתצוגה בכרטיסייה. |
| **`כתובת`** | כתובת המגורים. |
| **`טלפון`** | מספר טלפון קווי / ראשי (משמש לחיוג ולאיתור אחים). |
| **`שם האב`** | שם פרטי של האב. |
| **`שם האם`** | שם פרטי של האם. |
| **`סלולרי אב`** | מספר נייד של האב (משמש לחיוג ולאיתור אחים). |
| **`סלולרי אם`** | מספר נייד של האם (משמש לחיוג ולאיתור אחים). |
| **`ת.ז אב`** | תעודת זהות של האב (מזהה ראשי לאיתור אחים). |
| **`ת.ז אם`** | תעודת זהות של האם (מזהה ראשי לאיתור אחים). |
| **`כיתה ומחנך`** | שם הכיתה והמחנך, או הגדרת תפקיד לצוות (כגון: `צוות`, `מורה`, `מחנך`). |
| **`סטטוס`** | מצב רישום (ערכים כמו `עזב`, `סיים`, `לא פעיל` יעבירו את הכרטיסייה לסוף הרשימה). |

## ⚙️ אפיון טכני מפורט של הפונקציות והפעולות בקוד

להלן פירוט מלא של כל 15 הפעולות המרכיבות את מנוע המערכת בקובץ `index.html`:

### 1. טעינה ואתחול המערכת (`window.onload`)
* **תפקיד:** מופעלת אוטומטית עם פתיחת האפליקציה.
* **פעולה:** בודקת האם קיימים נתונים שמורים בזיכרון המקומי של הדפדפן תחת המפתח `students_data` ב-`localStorage`.
  * אם קיימים נתונים: מסתירה את מסך העלאת הקובץ, מציגה את ממשק החיפוש ומריצה את תצוגת הכרטיסיות.
  * אם אין נתונים: מציגה את אזור בחירת קובץ ה-CSV הראשוני.

### 2. מנוע פיענוח CSV (`parseCSV(text)`)
* **תפקיד:** המרת טקסט גולמי מקובץ CSV למערך של אובייקטים (רשומות JSON) תקניים.
* **פעולה:**
  * מסירה תווי בקרה נסתרים מתחילת הקובץ (`\uFEFF` - UTF-8 BOM).
  * מנתחת את השורה הראשונה כדי לזהות אוטומטית את תו ההפרדה הדומיננטי בקובץ (פסיק `,`, נקודה-פסיק `;` או טאב `\t`).
  * עוברת תו-אחר-תו ומטפלת נכון בשדות המוקפים במרכאות כפולות (כדי שפסיקים בתוך כתובות או הערות לא ישברו את סדר העמודות).
  * ממפה כל שורה לאובייקט שבו המפתחות הם שמות הכותרות המדויקים.

### 3. קליטת קובץ וניקוי זיכרון (`handleFile(e)`)
* **תפקיד:** טעינת קובץ CSV חדש מהמכשיר והחלפת בסיס הנתונים הקיים.
* **פעולה:**
  * קוראת את הקובץ שנבחר באמצעות `FileReader` ומפענחת אותו בקידוד `UTF-8`.
  * **איפוס מטמון יזום:** מוחקת לחלוטין את הנתונים הישנים (`localStorage.removeItem('students_data')`) לפני טעינת החדשים כדי למנוע התנגשויות או שאריות מידע.
  * שומרת את הנתונים החדשים ב-`localStorage`, מאפסת את תיבת החיפוש והבאנרים הפעילים, ומציגה הודעת אישור למשתמש.

### 4. מחולל כפתורי חיוג (`generatePhoneButtons(phoneStr, labelPrefix)`)
* **תפקיד:** יצירת קישורי חיוג ישירים מתוך שדות הטלפון.
* **פעולה:** מפצלת מחרוזת טלפונים (במקרה שיש יותר ממספר אחד מופרד ברווח, פסיק או נקודה-פסיק) ויוצרת עבור כל מספר תקני תגית `<a href="tel:...">` מעוצבת ככפתור ירוק.

### 5. נרמול ופענוח מספרים (`cleanNumeric(val)`)
* **תפקיד:** ניקוי מספרי טלפון ותעודות זהות לצורך תצוגה והשוואה מדויקת.
* **פעולה:**
  * מזהה מספרים שנשמרו בפורמט מדעי של אקסל (כמו `2.4E+08`) וממירה אותם חזרה למספר שלם תקני.
  * מסירה מקפים, רווחים, סוגריים ואפסים מובילים (`0`) מתחילת המספר.

### 6. איתור והצגת אחים (`showSiblingsByParent(...)`)
* **תפקיד:** שליפת כל הילדים השייכים לאותה משפחה בלחיצת כפתור.
* **פעולה:** מקבלת את מזהי ההורים מתוך כרטיסייה ספציפית (ת.ז. אב, ת.ז. אם, טלפון בית, סלולרי אב, סלולרי אם) ומסננת את כל מאגר הנתונים למציאת כל הרשומות שחולקות לפחות אחד מהמזהים הללו. מציגה באנר עליון עם מספר בני המשפחה שנמצאו וכפתור חזרה לרשימה המלאה.

### 7. איפוס חיפוש וסינון (`clearSearch()`)
* **תפקיד:** החזרת התצוגה למצב ברירת המחדל.
* **פעולה:** מרוקנת את שדה החיפוש, מסתירה את כפתור הניקוי (`✖`) ואת באנר סינון המשפחה, ומציגה מחדש את כל הרשומות במאגר.

### 8. חישוב גיל מדויק (`calculateAge(birthDateStr)`)
* **תפקיד:** חישוב גיל התלמיד/איש הצוות ביחס לתאריך הנוכחי במכשיר.
* **פעולה:**
  * תומכת בריבוי פורמטים: `D.M.YYYY`, `DD/MM/YYYY`, `DD-MM-YY`, וכן פורמט הפוך `YYYY-MM-DD`.
  * מחשבת את סך החודשים המלאים שעברו מיום הלידה ועד היום (תוך התחשבות ביום בחודש), ומחזירה מספר עשרוני בדיוק של ספרה אחת אחרי הנקודה (למשל: `13.3`).

### 9. זיהוי בוגרי ישיבה קטנה וגדולה (`isYeshikOrYeshig(classStr)`)
* **תפקיד:** זיהוי אוטומטי של תלמידים שעברו למסגרות המשך.
* **פעולה:** מנרמלת סוגי מרכאות וגרשיים שונים ובודקת האם בשדה הכיתה מופיעות המחרוזות `יש"ק`, `ישק`, `יש"ג` או `ישג` (בכל צירוף כגון `יש"ק - א'`).

### 10. זיהוי כיתות גבוהות (`isHigherThanHet(classStr)`)
* **תפקיד:** הבחנה בין תלמידי היסודי (עד כיתה ח') לבין כיתות גבוהות יותר.
* **פעולה:** בודקת האם בשדה הכיתה מופיעים סימונים של כיתות ט' ומעלה (אותיות `ט`, `י`, `יא`, `יב` או מספרים גדולים מ-8).

### 11. בניית הכרטיסיות ומיון חכם (`displayStudents(students)`)
* **תפקיד:** רינדור הכרטיסיות על המסך וסדר הופעתן.
* **פעולה:**
  * **אלגוריתם מיון תלת-שלבי:**
    1. **עדיפות עליונה (ציון 0):** אנשי צוות ותלמידים פעילים (מוצגים בראש הרשימה עם מספור רץ).
    2. **עדיפות ביניים (ציון 1):** תלמידים בכיתות גבוהות מ-ח' (מודגשים במסגרת צהובה-כתומה ותגית `🎓`).
    3. **עדיפות תחתונה (ציון 2):** תלמידים שסיימו/עזבו או נמצאים ביש"ק/יש"ג (מועברים לסוף הרשימה, מוצגים בגוון אפור-אדמדם ותגית `🚫`, ואינם נכללים במספור הרץ של הפעילים).
  * מזהה אנשי צוות לפי מילות מפתח (`צוות`, `מורה`, `מחנך`) ומעניקה לכרטיסייה שלהם עיצוב כחול מובחן.
  * מוסיפה כפתור `👨‍👩‍👧‍👦 הצג אחים` ליד פרטי ההורים.

### 12. נרמול טקסט לחיפוש (`normalizeSearchText(str)`)
* **תפקיד:** הכנת מחרוזות טקסט להשוואה גמישה.
* **פעולה:** ממירה לאותיות קטנות, מסירה גרשיים ומרכאות מכל הסוגים (`"`, `״`, `׳`, `'`) ומאחדת רווחים כפולים לרווח בודד.

### 13. מנוע חיפוש מדורג (`filterStudents()`)
* **תפקיד:** סינון בזמן אמת תוך כדי הקלדה בתיבת החיפוש.
* **פעולה:**
  * מפצלת את שאילתת החיפוש למילים בודדות ודורשת שכל המילים יופיעו ברשומה (תומכת בחיפוש משולב של שם פרטי + משפחה + כיתה/טלפון).
  * **ניקוד רלוונטיות:** מעניקה עדיפות עליונה (100+ נקודות) להתאמה בשם התלמיד או איש הצוות עצמו, ועדיפות משנית (10 נקודות) להתאמה בשם המחנך בלבד (כך שחיפוש שם של מחנך יציג קודם את הכרטיסייה של המחנך עצמו, ומיד אחריו את תלמידי כיתתו).

### 14. איפוס מלא של האפליקציה (`resetApp()`)
* **תפקיד:** התנתקות מקובץ הנתונים הנוכחי לטובת טעינת קובץ חדש.
* **פעולה:** מבקשת אישור מהמשתמש, מוחקת את מפתח `students_data` מ-`localStorage`, מאפסת את מערך הנתונים בזיכרון ומחזירה את מסך בחירת הקובץ.

### 15. רישום מעטפת אופליין (`Service Worker`)
* **תפקיד:** הבטחת זמינות האפליקציה ללא חיבור לרשת.
* **פעולה:** רושמת ברקע את הקובץ `sw.js` בעת טעינת העמוד (בפרוטוקול HTTP/HTTPS), כך שקובצי המערכת יישמרו במטמון הדפדפן וייטענו מיידית גם במצב טיסה או ללא קליטה.
